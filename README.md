# DSH 插件统一问题反馈

这里收 DeepSeek Harness 插件的问题反馈：

- 裁切插件 `dsh-log-prune`
- 工具箱 `dsh-toolbox`
- 其他插件

## 提 issue 前

1. 先跑一次插件面板里的「反馈 → 检测并生成」，把生成的信息粘进来（已脱敏，不含会话正文）。
2. 注明插件名和版本（如 `dsh-log-prune v0.2.18`）。
3. 能复现的步骤尽量写清楚：什么操作、什么现象、面板/日志里有没有报错。

## 反馈格式

```text
插件：
版本：
现象：
复现步骤：
生成的问题信息：（粘贴）
```
